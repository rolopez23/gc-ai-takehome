## 4. Data Processing Agreement (16 Checks)

| # | Check Name | Importance | Key Position / Description |
|---|-----------|------------|---------------------------|
| 1 | Types of Personal Data | High | All personal data categories processed must be listed; triggers if categories are undefined or overly broad |
| 2 | Purposes of Processing | High | Processing limited to specified purposes only; triggers if purposes are vague or unlimited |
| 3 | Data Subject Categories | Medium | All data subject categories must be listed; triggers if categories are absent |
| 4 | Processing Instructions | High | Processor acts only on documented instructions; triggers if processor has discretion beyond instructions |
| 5 | Confidentiality of Processing | Medium | Personnel authorized to process data are bound by confidentiality; triggers if obligation is absent |
| 6 | Security Measures | High | Appropriate technical and organizational measures required (Art. 32 GDPR standard); triggers if measures are vague |
| 7 | Subprocessor Management | High | Prior written consent for new subprocessors; triggers if notification-only or blanket approval |
| 8 | Subprocessor List | Medium | Maintained list of subprocessors; triggers if list is not available or not kept up to date |
| 9 | Data Subject Rights | High | Processor assists controller in responding to data subject requests; triggers if assistance is absent |
| 10 | Data Breach Notification | High | 48-hour breach notification to controller; triggers if window exceeds 48 hours |
| 11 | DPIA Assistance | Medium | Processor assists with DPIA and prior consultation; triggers if assistance is absent |
| 12 | Deletion / Return of Data | High | Deletion or return of all personal data at termination; triggers if obligation is absent |
| 13 | Audit Rights | Medium | Controller audit rights with 30-day notice; triggers if absent or heavily restricted |
| 14 | International Data Transfers | High | SCCs or equivalent safeguards required for transfers outside EEA; triggers if transfer mechanism is absent |
| 15 | Liability Allocation | High | Processor liable for damage caused by non-compliance; triggers if liability is excluded or limited below GDPR standard |
| 16 | Governing Law / Supervisory Authority | Medium | Governing law consistent with controller's jurisdiction; triggers if processor's jurisdiction is specified |
