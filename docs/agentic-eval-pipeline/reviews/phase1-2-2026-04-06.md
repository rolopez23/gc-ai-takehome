### Standard Review

#### Bugs
- **evaluator.py:129-145** — `handle_get_playbook` passes short agreement_type ("SaaS MSA") to `playbook.get_playbook()` which indexes by full names ("SaaS Master Service Agreement"). Every lookup raises KeyError, returning error to LLM. Playbook grounding is silently broken for all agreement types. · `[Valid — critical, must fix]`
- **evaluator.py:220-228** — If LLM never calls `report_evaluation` (end_turn after get_playbook error), `tool_results.get("report_evaluation", {})` returns empty dict. All fields default to `severity=0, fairness=""`. Empty-string fairness crashes `compute_overall_fairness` with `KeyError: ""`. · `[Valid — critical, must fix]`

#### Edge Cases
- **evaluator.py:196-203** — When `cross_ref_text` is `None` but clause has `cross_references`, the unresolvable-reference note is never appended. Only fires when some refs resolved but others not. · `[Valid — fix]`
- **synthesis.py:22** — `FAIRNESS_RANK[c["fairness"]]` has no guard for unexpected values (None, empty string). · `[Valid — fix]`
- **base.py:119** — `while True` tool-use loop has no iteration cap. If LLM repeatedly calls tools, loop runs indefinitely. · `[Valid — fix]`
- **synthesis.py:25-26** — If all clauses have `status="error"`, `evaluated` is empty and function returns "fair" instead of signaling failure. · `[Speculative — orchestrator >10% threshold should prevent, but function itself is unguarded]`

#### Error Handling
- **verifier.py:70** — `result.tool_results["verify_contract"]` uses direct dict access. If model hits max_tokens before tool call, KeyError crash. · `[Valid — fix]`
- **headline.py:89** — Same pattern: `result.tool_results.get("report_headline", {})` returns empty dict if tool not called, producing empty HeadlineResult. · `[Valid — fix]`
- **base.py:91-103** — No backoff delay between retries. Instant retries useless against rate limits (429). · `[Valid — fix]`
- **base.py:91-103** — Failed retry attempts silently swallowed with no logging. · `[Valid — fix]`

#### Contract Violations
- **evaluator.py:132 vs spec** — Spec says get_playbook takes agreement_type "from splitter output" (short names). But `playbook.get_playbook()` uses full names. No mapping in evaluator path. · `[Valid — same as bug #1]`
